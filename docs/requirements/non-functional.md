# Non-functional requirements

Status vocabulary: **Currently satisfied** = source plus available local validation supports the bounded claim; **Partially satisfied** = a control exists with gaps; **Not satisfied** = required mechanism absent; **Production requirement** = release evidence/configuration outstanding; **Future improvement** = valuable beyond current launch scope. These are engineering observations, not compliance certification.
