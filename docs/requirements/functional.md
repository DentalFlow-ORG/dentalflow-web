# Functional requirements and feature inventory

Stable catalog, reviewed 2026-09-20. 33 requirements: **23 Implemented, 4 Partially implemented, 1 Backend only, 1 Frontend only, 2 Missing, 1 Planned/documented only, 1 Deprecated**. Missing/planned entries describe explicit product gaps, not approved implementation work. No module is counted complete merely because a database table exists.

## Reading and traceability

For authenticated clinic actions, the common preconditions are an active user, valid Bearer token, valid role/clinic shape and authorized scope. Billing/plan checks apply only where declared in the [endpoint reference](../integrations/source-reference.md). Public/admin/onboarding exceptions are explicit below. “All” means all three current plans for the core capability, not every ancillary action on the screen. Rules link by RN number to the [business-rule catalog](business-rules.md).

Frontend paths below are relative to `src/features/`; backend paths are relative to `../dentalflow-api/src/modules/`. Each domain row maps to its controllers, DTOs and services through the generated API reference. Exact model fields and FKs are in the [database reference](../integrations/database-reference.md).
